Dan sebagian shalih biasa bepergian membawa huruf-huruf abjad yang di awal sūra; maka ia ditanya tentang itu dan berkata: "Berkahatnya nampak padaku, dan dengannya Allah Ta'ala menjagaku serta melapangkan rezekiku dan memeliharaku dari musuh, binatang buas, dan serangga hingga aku kembali pada keluargaku." * Dan disebutkan dari sebagian shalih bahwa ia mempunyai budak wanita yang tertidur dan bermalam di tempat yang tidak dilanggarnya terhadap tuannya, lalu ia epilepsi; maka tuannya bangkit dan membaca: { "Ḥā-Mīm 'Ayn-Sīn-Qāf, Nūn, dan Pena serta apa yang mereka tulis" } maka akalnya pulih dan tidak kembali padanya. Dan barangsiapa mengukir huruf-huruf bercahaya dalam bentuk bulat dari perak dengan ascendant Taurus dan bulan di dalamnya serta menyimpannya, ia tiada luput dari faedahnya. Dan Imam 'Alī raḍiyallāhu 'anhu berkata: "Aku melihat al-Khaḍir 'alaihissalām sehari sebelum perang Badar, lalu aku berkata kepadanya: 'Ajarkanlah aku sesuatu yang aku menangkan dengannya atas musuh.' Ia berkata: 'Bacalah: "Dengan nama Allah Yang Maha Pemurah lagi Maha Penyayang; Ya Allah, aku memohon kepada-Mu dengan hak { Alif-Lām-Mīm } dan { Alif-Lām-Mīm } dan { Alif-Lām-Mīm-Ṣād } dan { Alif-Lām-Mīm-Rā } dan { Rā } dan { Kāf-Hā-Yā-'Ayn-Ṣād } dan { Ṭā-Hā } dan { Ṭā-Sīn-Mīm } dan { Ṭā-Sīn } dan { Yā-Sīn } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Ḥā-Mīm } dan { Qāf } dan { Nūn } — wahai Yang Dia adalah Dia, wahai Yang tiada tuhan selain Dia, ampunilah aku dan tolonglah aku; sesungguhnya Engkau Mahakuasa atas segala sesuatu."' Dan ini adalah rahasia menyeluruh dan cahaya bercahaya, diletakkan pada hari Kamis di jam pertama sebagai bentuk lima lipat dalam tambang emas-perak atau perkamen, dan { Kāf-Hā-Yā-'Ayn-Ṣād } ditulis di dalamnya lima kali; lalu engkau membaca: 'Ya Allah, wahai Pemberi petunjuk, wahai Mulia, wahai Mengetahui, wahai Kekal, wahai Tuhanku, kabulkan hajatku yang demikian-demikian' — atau yang berkaitan akhirat — maka ia meraih yang dikehendaki. Adapun { Kāf-Hā-Yā-'Ayn-Ṣād }, padanya terdapat rahasia tersimpan: Kāf dari Kāfī (Cukup), Hā dari Hādī (Pemberi petunjuk), Yā dari Bārī (Mengadakan), 'Ayn 'Alīm (Mengetahui), Ṣād Ṣādiq (Benar) — demikian diriwayatkan dari 'Abd Allāh bin 'Umar dan Ibn 'Abbās. Dan dikatakan: 'Abd Allāh bin 'Abbās apabila berdoa membaca: "Wahai Cukup, berilah petunjuk; wahai Mengadakan, wahai Mengetahui, wahai Benar, kabulkan untukku demikian-demikian" — dan dikatakan ia adalah nama Allah Yang Paling Agung. Dan apabila engkau ingin diterima pada tokoh atau lainnya, atau seseorang tertentu yang mengabulkan hajatmu, ambillah perkamen gazelle dan tulislah keselarasan berikut, lalu asapi dengan styrax, mahlab, dan kayu gaharu, dan letakkan di kepalamu di depanmu — setiap hajat yang engkau arahkan terkabul dan Allah menolongmu atas musuhmu. Dan Amīr al-Mu'minīn 'Alī bin Abī Ṭālib raḍiyallāhu 'anhu bersabda tentang mereka dalam syair:
Dua puluh huruf bercahaya kukumpulkan * lima dan lima kubentuk, sempurna;
