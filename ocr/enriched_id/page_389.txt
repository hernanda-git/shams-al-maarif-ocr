yang dunawi, setelah pisah darinya jadi satu, tiap cenderung pada bentuknya. Maka saat berkumpul dan kembali, mereka namakan endapan "pada tiap tanah" dan "pada tiap tubuh"; mungkin raksa dinamai "air pertama" — itu tata tanah khusus: tanah mereka diambil dan dibakar api (jakal disebut). Bila takut api makan, disiram air berulang hingga putih dan keras, mereka bilang "campur raksa dengan abu." Pada belerang orang ada tiga kuasa: jadi, rawat, cerna. Api tujuh: kalsin padat; gumpal air (raksa); api unsur di rumah; api alam; api gumpal. Dhū al-Nūn: api tujuh pangkat menyala, tiga suam, genap sepuluh. Dikata sepuluh adalah kuasa alam belerang — berkuasa jadi, rawat, cerna. Yang jadi hanya hasilkan setetes di perut hingga lahir; merah lahir seperti anak, tak tahan keras api, seperti anak tak tahan makan kasar — disusui dulu bertahap. Begitu timbangan halus dulu lalu mengeras sedikit jadi tabiatnya. Kuasa rawat urus dan tambah tubuh hingga puncak lalu susut. Begitu yang lahir di campuran jiwa — bila larut dari bapak, mula sedikit urat lalu berkeringat; mungkin dinamai "susu ginjal" mula sedikit; mungkin jadi banyak bagian. Begitu susu di campuran mula kerja — namun bekerja pada tubuh ini, bila ulang padanya berbuat besar, tambah cerna dan analisisnya sedikit hingga banyak dan capai puncak naik. Lalu susut sedikit pada sublimasi dunianya dan kembali ke unsur asal di tubuh. Serupa tanah tempat tumbuh; begitu roh tak berdiri kecuali dengan tubuh, sebab roh cari pusatnya api dan tanah, pusat di bawah dan atas menyambung bawah. Makanan hanya dicerna panas dan lembap, sebab cerna jenis busuk, dan busuk huruf tubuh kasar lalu jadi roh penyelam setelah kasar kasar. Busuk dipakai kerja mereka, sandaran mereka; dengan busuk naik makanan dan turun ke usus bawah. Begitu cerdik — bila ambil jernih dari batu, namai jiwa, air belerang murni banyak nama; endapan sisa dinamai "pada tahi." Mereka perbanyak busuk, bilang "busukkan batu dengan tahi lembap" — itu saja, tiada tahi lain. Khālid: "Alam himpun jadi satu, ia asal, tiada lain, setuju mulia; asalnya pada tahi, maka tak anugerah." Itu makna "tujuh api batu mereka" seperti zat — jiwa, roh, tubuh, persegi sifat, empat alam api udara tanah air. Maka tujuh pada susun manusia, tubuh jadi hitam seperti tikus — hitam nyata — di dalam esensi murni. Cerdik: "Jangan gentar pada alam, kasar, kotor, hitamnya, sebab api kembalikan kotor dan hitam jadi murni dan cahaya satu."
