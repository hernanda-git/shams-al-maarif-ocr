Arabic:
— ٢٦٢ —

( وَرَدُ يَوْمِ الأَحَدِ )

بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ ۞ «اللَّهُمَّ، يَا مُجْرِيَ النِّيلِ، وَسَاخِّرَ الفِيلِ، وَفَالِقَ البَحْرِ لِبَنِي إِسْرَائِيلَ — اللَّهُمَّ، سَخِّرْ لِي مَا أُرِيدُ، أَنَّكَ فَعَّالٌ لِمَا تُرِيدُ. يَا إِلَهِي، أَسْأَلُكَ أَنْ تُيَسِّرَ لِي مَا أُرِيدُ — يَا خَيْرَ نَاصِرٍ، وَخَيْرَ مُعِينٍ — بِحَقِّ { الحَمْدُ لِلَّهِ رَبِّ العَالَمِينَ }. أَعِنِّي عَلَى كُلِّ أَمْرٍ بِقُدْرَتِكَ يَا رَحْمَنُ يَا رَحِيمُ — بِحُرْمَةِ سُورَةِ يس، وَبِحُرْمَةِ سَيِّدِ المُرْسَلِينَ، حَبِيبِ رَبِّ العَالَمِينَ، مُحَمَّدٍ صَلَّى اللَّهُ عَلَيْهِ وَسَلَّمَ، وَبِحَقِّ { بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ ۞ يس ۞ وَالقُرْآنِ الحَكِيمِ } إِلَى قَوْلِهِ { فِي إِثْمٍ مُّبِينٍ }.

أَقْسَمْتُ عَلَيْكُمْ يَا مَعْشَرَ الرُّوحَانِيَّةِ بِعِزِّ اللَّهِ وَرَسُولِهِ، وَبِنُورِ وَجْهِ اللَّهِ، وَبِحَقِّ اسْمِ اللَّهِ، وَبِحَقِّ { الحَمْدُ لِلَّهِ رَبِّ العَالَمِينَ } — يَا حَيُّ يَا قَيُّومُ، يَا كَافِي يَا شَافِي — اهْدِنِي إِلَيَّ؛ يَا بَاقِي، أَجِبْ. يَا رُوقَايِئِيلَ، وَأَنْتَ يَا مُذْهِبُ — سَامِعًا مُطِيعًا بِحَقِّ { الحَمْدُ لِلَّهِ رَبِّ العَالَمِينَ }، وَبِحَقِّ { الحَيِّ القَيُّومِ }، وَبِحَقِّ { المَلِكِ الغَالِبِ عَلَيْكَ أَمْرُهُ }، أَجِبْ — وَبِحَقِّ لِيهَطَطِيلَ. { وَجَاءَ الحَقُّ وَزَهَقَ البَاطِلُ } الآيَةَ.

أَقْسَمْتُ عَلَيْكَ يَا رُوقَايِئِيلَ، وَالمَلِكِ المُذْهِبِ، بِحَقِّ { المَلِكِ المَعْبُودِ } — { سُبْحَانَ المُنَفِّسِ عَنْ كُلِّ مَدِينٍ }، { سُبْحَانَ المُخَلِّصِ لِكُلِّ مَسْجُونٍ }، { سُبْحَانَ المُفَرِّجِ عَنْ كُلِّ مَحْزُونٍ }، { سُبْحَانَ مَنْ أَجْرَى المَاءَ فِي البِحَارِ وَالعُيُونِ }، { سُبْحَانَ مَنْ خَزَائِنُهُ بَيْنَ الكَافِ وَالنُّونِ }، { سُبْحَانَ مَنْ إِذَا أَرَادَ شَيْئًا أَنْ يَقُولَ لَهُ «كُنْ فَيَكُونُ» إِلَى آخِرِهَا }.

اللَّهُمَّ، سَخِّرْ لِي المَلِكَ رُوقَايِئِيلَ — كَمَا سَخَّرْتَ البَحْرَ لِمُوسَى عَلَيْهِ السَّلَامُ، وَالنَّارَ لِإِبْرَاهِيمَ، وَالجِبَالَ لِدَاوُدَ، وَالرِّيحَ وَالجِنَّ وَالإِنْسَ لِسُلَيْمَانَ، وَالشَّمْسَ وَالقَمَرَ وَالنُّجُومَ وَجَمِيعَ الأَشْيَاءِ لِنَبِيِّنَا مُحَمَّدٍ صَلَّى اللَّهُ عَلَيْهِ وَسَلَّمَ. أَسْأَلُكَ أَنْ تُسَخِّرَ لِي المَلِكَ رُوقَايِئِيلَ بِقَضَاءِ حَاجَتِي — بِحَقِّ اسْمِكَ العَظِيمِ الأَعْظَمِ، وَبِحَقِّ أَسْمَائِكَ الحُسْنَى: يَا اللَّهُ، يَا سَرِيعُ، يَا قَرِيبُ، يَا مُجِيبُ، يَا بَاسِطُ، يَا وُدُودُ، يَا ذَا العَرْشِ المَجِيدِ، يَا مُبْدِئُ، يَا مُعِيدُ، يَا فَعَّالُ لِمَا يُرِيدُ. أَسْأَلُكَ بِنُورِ وَجْهِكَ الَّذِي مَلأَ أَرْكَانَ عَرْشِكَ، وَبِقُدْرَتِكَ الَّتِي قَدَّرْتَ بِهَا عَلَى جَمِيعِ خَلْقِكَ، وَبِرَحْمَتِكَ الَّتِي وَسِعَتْ كُلَّ شَيْءٍ — يَا غِيَاثَ المُسْتَغِيثِينَ، أَغِثْنِي ٣، وَأَعِنِّي عَلَى عَمَلِي هَذَا فِي هَذِهِ السَّاعَةِ، وَاقْضِ حَاجَتِي. يَا اللَّهُ، يَا غِيَاثَ المُسْتَغِيثِينَ، أَغِثْنِي — يَا رَحْمَنُ بِرَحْمَتِكَ، يَا أَرْحَمَ الرَّاحِمِينَ.

اللَّهُمَّ، سَخِّرْ لِي المَلِكَ رُوقَايِئِيلَ — { قَدْ شَغَفَهَا حُبًّا } — { يُحِبُّونَهُمْ كَحُبِّ اللَّهِ، وَالَّذِينَ آمَنُوا أَشَدُّ حُبًّا لِلَّهِ } — { يُحِبُّهُمْ وَيُحِبُّونَهُ } — { كُلًّا لَا تُطْعِمُهُ وَاسْجُدْ وَاقْتَرِب }.

( وَرَدُ يَوْمِ الاِثْنَيْنِ )

تَقُولُ: { وَاضْرِبْ لَهُم مَّثَلًا أَصْحَابُ القَرْيَةِ } إِلَى قَوْلِهِ { البَلَاغُ المُبِينُ }؛ ثُمَّ تَقُولُ: «الرَّحْمَنُ الرَّحِيمُ، يَا رَحْمَنُ يَا رَحِيمُ، يَا اللَّهُ، يَا رَؤُوفُ، يَا عَطُوفُ، يَا جَابِرُ، يَا جَبَّارُ، يَا جَبِيرُ — سَامِعًا مُطِيعًا بِحَقِّ { الرَّحْمَنِ الرَّحِيمِ }، وَبِحَقِّ { الرَّؤُوفِ العَطُوفِ }، وَبِحَقِّ { المَلِكِ الغَالِبِ عَلَيْكَ أَمْرُهُ } — هُوزُوجَ، مَهْطِيلَ. { وَقَدَّمْنَا إِلَى مَا عَمِلُوا مِنْ عَمَلٍ فَجَعَلْنَاهُ هَبَاءً مَّنثُورًا } — اللَّهُمَّ، سَخِّرْ لِي المَلِكَ هَطَيَائِيلَ، وَمُرْهُ بِقَضَاءِ حَاجَتِي». ثُمَّ تَقُولُ: { سُبْحَانَ المُنَفِّسِ عَنْ كُلِّ مَدِينٍ }، { سُبْحَانَ المُخَلِّصِ لِكُلِّ مَسْجُونٍ }، { سُبْحَانَ المُفَرِّجِ عَنْ كُلِّ مَحْزُونٍ }، { سُبْحَانَ مَنْ أَجْرَى المَاءَ فِي البِحَارِ وَالعُيُونِ }، { سُبْحَانَ مَنْ خَزَائِنُهُ بَيْنَ الكَافِ وَالنُّونِ }، { سُبْحَانَ مَنْ إِذَا أَرَادَ شَيْئًا أَنْ يَقُولَ لَهُ «كُنْ فَيَكُونُ» } إِلَى آخِرِهَا.

( Litanies hari Ahad ) "Dengan nama Allah Yang Maha Pengasih lagi Maha Penyayang" — "Ya Allah, wahai Yang mengalirkan Nil, wahai Yang menundukkan gajah, wahai Yang membelah laut bagi Bani Isra'il — ya Allah, tundukkanlah bagiku apa yang kuinginkan, bahwa Engkau Maha Kuasa atas apa yang Engkau kehendaki. Wahai Tuhanku, aku memohon pada-Mu semoga Engkau mudahkan bagiku apa yang kuinginkan — wahai sebaik-baik Penolong, sebaik-baik Pembantu — dengan hak { Segala puji bagi Allah Rabbul 'alamin}. Tolonglah aku dalam setiap urusan dengan kekuasaan-Mu wahai Ar-Raḥmān, wahai Ar-Raḥīm — dengan kemuliaan surah Yā-Sīn, dan dengan kemuliaan penghulu para rasul, kekasih Rabbul 'alamin, Muḥammad shallallāhu 'alaihi wa sallam, dan dengan hak { Dengan nama Allah Yang Maha Pengasih lagi Maha Penyayang — Yā-Sīn — dan al-Qur'ān yang hakím} hingga firman-Nya { dalam kesesatan yang nyata}. Aku menyumpah kamu wahai golongan rohani, demi kemuliaan Allah dan rasul-Nya, dan cahaya wajah Allah, dan hak nama Allah, serta hak { Segala puji bagi Allah Rabbul 'alamin} — wahai Yang Hidup, wahai Yang Berdiri Sendiri, wahai Yang Mencukupi, wahai Yang Menyembuhkan — tunjukilah aku pada diriku; wahai Yang Kekal, penuhilah. Wahai Rūqāyīl, dan engkau wahai Yang Menghilangkan — mendengar lagi taat dengan hak { Segala puji bagi Allah Rabbul 'alamin}, dan hak { Yang Hidup lagi Berdiri Sendiri}, dan hak { Raja yang perintah-Nya berkuasa atasmu}, penuhilah — dan dengan hak Līhaṭaṭīl. { Dan datanglah kebenaran serta lenyaplah kebatilan} ayat itu. Aku menyumpah engkau wahai Rūqāyīl, dan raja yang menghilangkan, dengan hak { Raja yang disembah} — { Maha Suci Yang Membebaskan setiap berhutang}, { Maha Suci Yang Memurnikan setiap orang dipenjara}, { Maha Suci Yang Membuka bagi setiap bersedih}, { Maha Suci Yang mengalirkan air di laut dan mata air}, { Maha Suci Yang perbendaharaan-Nya di antara Kāf dan Nūn}, { Maha Suci Yang apabila menghendaki sesuatu berkata padanya 'Jadilah maka jadilah ia' hingga akhirnya}. Ya Allah, tundukkanlah bagiku raja Rūqāyīl — sebagaimana Engkau menundukkan laut bagi Mūsā 'alaihis-salām, dan api bagi Ibrāhīm, dan gunung bagi Dāwūd, dan angin serta jin dan manusia bagi Sulaimān, dan matahari, bulan, bintang, dan segala sesuatu bagi nabi kita Muḥammad shallallāhu 'alaihi wa sallam.
