## Findings and reusable lessons

1. **Physical index is not printed folio.** Page 71's source prints 15; targets retain `— 15 —`, not an invented 65. Original Arabic numerals remain unchanged in embedded source; targets use Latin numerals under the Latin-only rule.
2. **A clean triage report is not semantic approval.** Page 68 pre-triage was clean but its garbled passages and source fidelity still needed actual translation review. The diagnostic triage command can exit zero while listing issues; inspect its findings.
3. **Preserve contradictions and repetition.** Nine-letter claims, repeated letters/Names, inconsistent source counts, incomplete quotation edges and obscure formulas remain source-bound. Page 76 has exactly three `(3)` markers at their source positions.
4. **Name the actor.** A sentence break followed by “He” can still be ambiguous. Divine actions beside a named prophet need an explicit divine subject, followed by fresh independent review if the reviewer edits the wording.
5. **Separate Git bytes from checkout newline conventions.** The first final-log verifier incorrectly compared committed LF bytes directly to a mixed-newline Windows working file. Corrected verification proves the committed baseline is an exact prefix and the working log equals Git after CRLF-only normalization. The log itself was not rewritten to satisfy the check.
6. **Separate test runners and interpreter environments.** Unittest discovery alone does not cover pytest fixtures/functions. Use the discovered executable and an isolated pytest environment; do not invent a PATH dependency or modify the application to fix the operator environment.
7. **Preserve WIP without overstating evidence.** The pre-existing deleted plan and untracked `.commandcode/` and campaign prompt remain outside all batch commits. The initial baseline captured their path/status, not every unrelated file's raw bytes.
